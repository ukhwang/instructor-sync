이 프로젝트는 운동숙제이며 저장소 AGENTS.md를 작업 규칙의 기준으로 사용한다.
docs/README.md에서 요청에 필요한 최소 문서만 선택해 읽는다.
단계 작업을 시작·재개할 때 docs/EXECUTION_CONTROL.md의 현재 단계·증거·차단 사유·다음 단계를 확인한다.
최근 맥락이 필요하면 docs/LATEST_HANDOFF.md를 읽고 계획과 현재 구현을 구분한다.
비단순 작업은 시작 전에 허가된 범위와 검증 가능한 완료 조건을 정한다.
중간 구현에서 멈추지 말고 허가된 범위 안에서 검사·수정과 완료 절차까지 끝낸다.
확인된 사실은 근거를 밝히고 추론과 제안을 구분하며 미확정 정책을 임의로 확정하지 않는다.
중요한 새 기능·제품 정책·파일럿 범위·사용자 흐름·운영 결정은 구현 전에 homework-practical-review를 사용한다.
데이터·인증 작업에는 homework-data-integrity를 사용한다.
출시 판정에는 homework-release-gate를 사용한다.
Skill 목록보다 실제 설치 경로의 이름·설명을 확인하며, 필요한 Skill이 없으면 미설치를 알리고 대체 검토를 Skill 사용으로 표기하지 않는다.
기존 변경을 보존하고 같은 작업트리를 동시에 수정하지 않으며 외부 배포·업로드·실데이터·파괴적 작업은 명시적 승인 전 금지한다.
단계 완료 시 EXECUTION_CONTROL의 공통 완료 절차에 따라 상태·증거·남은 위험·다음 단계를 갱신한다.
사용자에게 핵심 결과 → 검증 → 남은 위험 → 다음 행동 순서로 간결하게 보고하며, 파일·Skill 접근이 없으면 확인한 척하지 않는다.
