# 운동 카탈로그 데이터 계약

상태: 스키마 적용, 콘텐츠 검토 대기

운동 카탈로그는 검색과 안내를 위한 공통 자료다. 회원별 처방과 수행 결과는 숙제 snapshot과 기록 테이블에 별도로 보존한다.

- `name`: 게시되는 대표 운동명
- `aliases`: 한글·영문·현장 별칭
- `category`, `tags`, `equipment`: 검색 조건
- `default_cue`: 강사가 수정할 수 있는 초안 큐
- `default_effort_kind`, 기본 횟수/시간: 입력 보조값이며 처방이나 의료 지시가 아님
- `media_url`, `media_alt`: 사용 권한과 대체 텍스트를 확인한 자료만 입력
- `source_note`: 출처 또는 내부 검토 근거
- `content_version`: 설명·미디어 변경 시 증가
- `status`: `draft`는 검색되지 않으며 검토가 끝난 `published`만 강사 검색에 노출

운동 효과, 통증 원인, 질환별 처방을 자동으로 기록하지 않는다. 기존에 발송한 숙제는 생성 당시 이름·큐·세트·횟수·미디어 버전을 보존해야 한다.
