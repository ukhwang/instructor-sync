# 🤖 AI 협업 보고서 (AI Collaboration Report)

## 1. 개요
본 프로젝트는 AI를 단순 코드 생성 도구가 아닌, **기획-설계-구현-검증-문서화** 전 과정의 협업 파트너로 활용했습니다.  
목표는 개발 속도만 높이는 것이 아니라, **코드 정합성·보안·재현성**을 함께 확보하는 것이었습니다.

## 2. 도구 활용 범위
- **Runtime AI**
  - OpenAI `gpt-4o-mini`: 지식 갭 및 교수 가이드 생성
  - Tavily API: 최신 웹 스니펫 수집(검색 증강)
- **SDLC 보조 AI**
  - Cursor 등 AI 개발 보조 도구군: 기획 정리, 코드 초안, 리팩터링 아이디어, 문서 점검
  - 외부 LLM 도구: 보안/문구/구조 검토 보조
- **최종 의사결정**
  - 실행 결과, 코드 리뷰, 테스트를 기준으로 팀이 확정

## 3. 협업 프로세스
1. 요구사항/기획 초안 작성  
2. 구조 설계 및 구현 초안 생성  
3. 실행 로그 기반 오류/예외 케이스 보완  
4. 문서-코드 정합성 점검  
5. 제출 직전 보안 체크(키/토큰/환경변수)

## 4. 기술 정합성 포인트
- FastAPI(`/api/analyze`)와 Next.js Edge(`/api/summarize`) 역할 분리
- `VERSION_AND_WEB_POLICY` 기반 환각 리스크 완화
- `ReportSummarySchema`(Zod) 검증을 통한 응답 안정성 보강
- `.ipynb`/`.pdf` 처리 경로 구분, 청크 상한 기반 비용 통제

## 5. 보안/리스크 대응
- `.env*` Git 추적 차단 정책 준수
- 원격 URL 토큰 노출 이슈 확인 후 재발급/재설정 절차 수행
- 제출 문서에서 미구현 항목은 로드맵으로 분리

## 6. 결과
- MVP 기능(분석, 요약/브리핑, 리포트 저장) 완성
- README 및 제출 문서 정합성 고도화
- AI 협업 증빙 문서(보고서/지침서/로그) 체계화
