# 운동 DB 초안 검토표 — 스쿼트·푸시업·플랭크

작성일: 2026-09-22. 전문 콘텐츠 검토 전 / 운영 반영 없음.

사용자가 제공한 퍼플렉시티 원문을 보존하고 기존 프로젝트 안에 로컬 PGlite 검토 DB를 만들었다. 기존 Supabase 테이블이나 앱 검색을 대체하지 않는다. 세부 데이터는 [initial-drafts.json](../data/exercise-catalog/initial-drafts.json), 입력 원본은 [perplexity-source.txt](../data/exercise-catalog/perplexity-source.txt), 사용법은 [README](../data/exercise-catalog/README.md)에 있다.

## 원본에서 바로 사용하지 않은 내용

1. 서로 다른 변형을 별칭 하나로 합치지 않았다. 백 스쿼트·의자에서 일어서기·무릎 푸시업·하이 플랭크는 별도 후보이며 위 3개와 동일 항목으로 검색되게 하지 않았다.
2. 스쿼트 발끝 각도/깊이 기준과 평가 실패 횟수, 푸시업 팔꿈치 각도/최대반복 평가 규칙을 모든 회원의 수행 기준으로 복사하지 않았다.
3. 스쿼트 비율은 첨부에서 ascent:descent로 썼지만 [원문 검색 결과](https://pmc.ncbi.nlm.nih.gov/articles/PMC4262933/)는 descent:ascent로 나온다. 원문 본문 직접 열기는 접근 확인 화면으로 막혔으므로 검색 발췌 수준만 확인했다. 비율과 시간/속도 의미를 더 확인하기 전에는 타이머 입력값으로 사용하지 않는다.
4. 푸시업 [연구 링크](https://pmc.ncbi.nlm.nih.gov/articles/PMC9362895/)는 대학 연령 여성 대상 척도 연구로 검색되었다. 평가 기준을 모든 회원의 숙제 처방으로 일반화하지 않는다. 본문 전체와 첨부의 개별 주장 대응은 미검증이다.
5. 플랭크 30~60초·3~5세트·휴식 30초를 기본값으로 넣지 않았다. 각 운동의 reps/sets/hold/rest/cadence 모두 null이다.
6. 중단 문구는 원본에 회원용과 강사용 지시가 섞여 있어 member.pause_note=null로 보류했다. 원문 전체는 보존했고, 이 항목의 사람 검토 전에는 게시할 수 없다.
7. 이미지/영상은 추가하지 않았다. 출처 링크를 읽을 수 있다는 사실은 재사용 권리 확인이 아니다.

| PMC 푸시업 논문 | 제목/검색 발췌 | 본문 평가 조건, 개별 큐가 실제 본문에 있는지 |

| [Banner Health 플랭크](https://www.bannerhealth.com/healthcareblog/advise-me/how-to-do-a-plank-right-and-get-the-most-benefits) | 본문 열람; 전완 지지·호흡·자세 안내 부분 확인 | 회원별 적용, 첨부의 모든 증상·조정 주장, 재사용 권리 |

page_retrieved는 자료를 가져왔다는 뜻, search_excerpt_only는 검색 발췌만 확인했다는 뜻이다. 둘 다 임상 검토 완료가 아니다. 문구의 source_ids는 검토 대상 연결이며 확인된 근거로 승격하지 않았다. 발행일도 원본의 reported 값으로만 보존한다.

## 점검·보완 순서

1. **변형 확인:** 원장이 실제 사용하는 동작이 위 3개 정의와 맞는지 확인한다. 다른 변형은 새 stable_key로 분리한다.
2. **문구 확인:** 운동별 집중 포인트 1~2개와 시작/수행 설명을 다듬는다. 수정한 문장의 근거를 직접 확인한다.
3. **중단·조정 안내:** 회원용 문장과 강사 전용 판단 자료를 분리하고 조정 후보의 적용 조건을 기록한다.
4. **출처·권리:** 구체적인 문장과 원문 위치를 연결한다. 근거를 찾지 못하면 삭제 또는 보류한다.
5. **운영 연결:** 검토 완료 후에만 기존 Supabase 계약으로 변환할 adapter/migration과 공개 snapshot 전달을 구현·검증한다. 현재 local draft를 기존 provider로 직접 읽히지 않는다.

초안 내용을 수정해 재등록할 때 content_version을 증가시킨다. 검토 DB의 기존 버전은 보존된다. 검토 완료와 운영 게시 기능은 아직 구현하지 않았으며, 이 도구는 초안만 받도록 제한했다.
