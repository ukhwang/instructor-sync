# 운동 콘텐츠 1차 검토 대기표

점검일: 2026-09-22

현재 운동 검색은 `lib/exercises/provider.ts`의 published DB provider와 기존 seed fallback을 함께 사용한다. seed fallback은 호환을 위한 기존 기본 목록이며, DB에서 콘텐츠 검토를 완료했다는 뜻이 아니다. 운영 `exercise_catalog`에 새 콘텐츠를 게시하거나 기존 seed를 published DB row로 복제하지 않았다.

## 게시 전 확인 항목

- 대표명·별칭·도구·태그가 현장 사용과 맞는지
- 일반적인 동작 안내로 적절한지, 질환 치료·통증 개선을 단정하지 않는지
- 설명과 미디어의 출처 및 사용 권한
- 대체 텍스트와 콘텐츠 버전
- 검토자와 검토일

현재 검토 완료 0개, DB published 신규 콘텐츠 0개다. 콘텐츠 검토가 끝나기 전에는 `reviewed_by`, `reviewed_at`, `source_note`를 임의로 채우거나 게시하지 않는다.
