## 1. 프로젝트 개요 및 핵심 가치 (Core Pitch)

### 1.1 서비스 정의
- **운동숙제 (instructor-sync)**는 원장이 직접 수업과 관리를 전담하는 **1인 PT샵 / 소형 필라테스 스튜디오(국내 4만 개소)**를 위한 **AI 숙제 & 수업 일원화 B2B SaaS**입니다.
- **공모전 출품작**: 'AI 쉬운 창업' 공모전 출품 및 실제 상용 SaaS 런칭을 목표로 개발 중입니다.

### 1.2 핵심 피칭 슬로건
> **"단순한 숙제 관리 앱이 아닙니다. 월 2.9만 원으로 150만 원짜리 PT 재등록 1건을 더 잡아주는 AI 부원장입니다."**

### 1.3 무과금 고마진 비즈니스 모델 (BM)
- **고정 인프라 비용 0원**:
  - Vercel Hobby Free Tier (서울 리전 icn1)
  - Supabase Free Tier (인증, PostgreSQL, RPC)
  - 카카오톡 공유: Web Share API 및 클립보드 다이렉트 딥링크 (별도 유료 알림톡 비용 0원 유지, 상용화 시 알림톡 확장 가능)
- **AI 호출 비용**: 회원 25명 기준 센터당 월 약 120원 미만 (규칙 기반 경량 엔진 + 필요시 GPT-4o-mini / Claude 3.5 Haiku 하이브리드)
- **수익성**: 월 29,000원 Starter 플랜 과금 시 **순마진 99.5%**의 압도적인 현금 흐름 구조.

## 2. 지금까지의 전체 작업 타임라인 (11단계 커밋 히스토리)

1. **1단계 (기반 구축 & 프로토타입 전환)**: Next.js 16 App Router + Supabase DB/인증 + 24자리 암호학적 난수 매직링크 토큰(`[token]`) 체계 완비.
2. **2단계 (클로드 오퍼스 3대 UI 수령 & 통합)**:
   - `QuickAssignDrawer` (원장용 빠른 숙제 출제 바텀시트)
   - `MemberHomeworkClient` (4060 시니어 원터치 회원 뷰)
   - `MilestoneReportCard` (10회차 마일스톤 리포트 카드)
   - `lib/types.ts` 통합 및 Server Actions 구축.
3. **3단계 (4060 시니어 60fps 회원 뷰 실배포)**: 카톡 링크 터치 즉시 0초 진입, 64px 왕버튼 세트 완료 체크, 30초 휴식 카운트다운, STT 음성 소감 입력 구현 (`01cfd1c`).
4. **4단계 (GitHub 오픈소스 운동 DB 미디어 CDN 연동)**: GitHub Raw 직결 무한루프 가이드 GIF(1,324종) 및 포스터(876종) CDN 파이프라인 탑재 (`9fd2a66`).
5. **5단계 (데모 토큰 독립 폴백 & Vercel 빌드 가드)**: `/h/demo-token` DB 장애 시에도 100% 렌더링 독립 폴백, npm legacy-peer-deps 안정화 (`d2fbaf6`).
6. **6단계 (수업 전 3초 AI 브리핑 카드 탑재)**: 회원 숙제 피드백을 수업 1분 전 대시보드 상단에서 3초 만에 브리핑받는 `SessionBriefingCard` Vercel 프로덕션 실배포 (`b107341` -> `7f2d5fe`).
7. **7단계 (Vercel 서울 리전 icn1 전환)**: 기존 시드니(`syd1`) 리전으로 잡혀 있던 Vercel 인프라를 서울(`icn1`)로 전격 전환하여 핑 150~200ms 지연 완전 해소 (`3cf809b`).
8. **8단계 (재활 마스터 DB 구축 & 가로 카드 슬롯 UI)**:
   - 5대 부위(허리, 고관절, 어깨, 무릎, 목) 임상 재활 34종 DB 구축.
   - 텍스트 입력창 전면 삭제, 가로 네모 카드 슬롯, `[-/+]` 세트 스테퍼, '푸시' 동의어 퍼지 검색 실배포 (`e8927a8`).
9. **9단계 (Pacefit 코칭 태그 · 카톡 원터치 모달 · 구형 창 폐기)**:
   - 운동별 1:1 맞춤형 코칭 태그(`#척추 중립`, `#갈비뼈 닫기` 등 34종 전수 매핑).
   - iOS 사파리 비동기 Web Share 차단 방어 동기식 카톡 공유 모달.
   - 구형 정밀 작성창(`/app/homework/new`) 전면 폐기 및 바텀시트 일원화 (`a2f6a21`).
10. **10단계 (60fps 토스형 마이크로 모션 그래픽)**:
    - Toss 곡선(`ease: [0.16, 1, 0.3, 1]`) 기반 `MotionPageTransition` 라우트 전환 (0.22s).
    - 가로 카드 슬롯 `<motion.div layout>` 물리 스프링 (`damping: 26, stiffness: 320`).
    - 버튼 `scale(0.90~0.96)` 쫀득한 햅틱 감쇠 및 탭 잔상 제거 (`d581941`).
11. **11단계 (1,334종 통합 마스터 DB & Server Action 경계 분리)**:
    - 클로드 오퍼스 검토 완료 1,334종 통합 운동 DB (`lib/exercises/master-db.ts`) 무중단 탑재.
    - Server Action-Client boundary Zod 스키마 격리 (`lib/homework-schemas.ts`)로 직렬화 에러 해결.
    - `ACTIVE_HOMEWORKS_CACHE` 인메모리 캐시 장착으로 0초 반응성 확보 (`5d5f4db`).

## 3. 핵심 기획 및 유저 플로우 (User Flows)

### 3.1 원장 축: 10초 원루프 플로우 (1타 2피 모델)
- **철학**: "수업 준비(브리핑 확인) → 수업 진행 → 수업 기록 & 숙제 출제"가 분리되지 않고 하나의 루프로 종결.
- **플로우**:
  1. 원장 대시보드(`/app`)에서 오늘 수업할 회원 카드의 `+ 빠른 숙제 작성` 터치.
  2. 1,334종 통합 DB 실시간 검색(초성 'ㄷㄷㅂㄱ', 동의어 '푸시') 또는 5대 재활 프리셋 선택.
  3. 가로 카드 슬롯에서 `[-/+]`로 세트/반복 조절 및 운동별 코칭 태그 칩 원터치 선택.
  4. 노란색 `[카카오톡으로 숙제 보내기]` 버튼 터치.
  5. 동기식 공유 모달 오픈 → [카카오톡 전송] 터치 시 회원의 갠톡 또는 단톡방으로 24자리 매직링크 전송.
  6. **동시에 해당 내역이 회원의 수업 기록으로 자동 저장**되어 별도 일지 작성이 불필요.

### 3.2 회원 축: 4060 시니어 0초 진입 무조작 뷰 (`/h/[token]`)
- **철학**: 40~60대 회원에게 로그인, 앱 설치, 복잡한 입력을 요구하면 90% 이상 이탈.
- **플로우**:
  1. 카톡 링크 터치 즉시 진입 (로그인 없음, 회원가입 없음, 개인정보 노출 없는 암호학적 토큰).
  2. 1번 운동 가이드 GIF 무한루프 자동 재생 (자세 확인).
  3. **64px 왕버튼 세트 완료** 터치 → 쫀득한 햅틱 진동 + 30초 휴식 카운트다운.
  4. 모든 세트 완료 후 이모지 3종(`👍 좋았어요`, `🤔 보통이에요`, `😣 아팠어요`) 터치.
  5. 통증 점수 슬라이더(0~10) 및 통증 부위 칩 선택 + 음성(STT)/텍스트 소감 제출.

### 3.3 피드백 & 10회차 재등록 클로징 루프
- **수업 1분 전 3초 브리핑**: 회원이 제출한 피드백이 원장 대시보드 상단 `SessionBriefingCard`에 즉각 반영되어 오프닝 멘트 생성.
  - *예시*: "지욱 님, 어제 데드버그 3세트 하실 때 허리 뻐근함이 6점이셨네요! 오늘 수업은 흉추 가동성 먼저 풀고 들어갈게요."
- **10회차 마일스톤 리포트 (`/report/[token]`)**:
  - 통증 완화 시각화 (예: 허리 통증 7점 → 2점 완화 그래프).
  - 숙제 성실도 80% 달성 배지.
  - 원장이 카톡으로 전송 시 회원 본인 및 가족이 함께 확인 → **하단 [다음 10회 재등록 상담하기] 버튼으로 150만 원 PT 재등록 원터치 클로징**.

## 4. 디자인 시스템 & 인터랙션 최적화

### 4.1 4060 시니어 친화 UI
- 본문 폰트 18~20px, 고대비 텍스트 (`text-stone-900`, `bg-white`).
- 모든 터치 타깃 최소 56~64px 이상 확보.
- `-webkit-tap-highlight-color: transparent`로 모바일 사파리 특유의 회색/파란색 탭 잔상 완전 제거.

### 4.2 60fps 토스 스타일 마이크로 모션
- **라우트 트랜지션 (`components/motion/MotionPageTransition.tsx`)**:
  - Next.js App Router `usePathname` 감지.
  - Cubic-bezier 곡선: `ease: [0.16, 1, 0.3, 1]`, duration: 0.22s.
  - `will-change: transform`, `y: 8px → 0px` 부드러운 페이드 슬라이드 업.
- **물리 스프링 가로 카드 슬롯 (`components/homework/QuickAssignDrawer.tsx`)**:
  - `<AnimatePresence mode="popLayout">` 및 `<motion.div layout>`.
  - Spring 옵션: `damping: 26`, `stiffness: 320`.
  - 운동 추가 시 부드럽게 솟아오르고, 삭제 시 주변 카드들이 스르륵 제자리 재정렬.
- **쫀득한 햅틱 피드백**:
  - 버튼 클릭 시 `active:scale-[0.92~0.97]` 감쇠.
  - 세트 조절 `[-]`/`[+]` 버튼 `active:scale-85`.

## 5. 성능 및 런타임 안정성 가드

1. **서울 리전 (`icn1`) 배포**: TTFB 30ms 수준으로 초고속 응답.
2. **1,334종 마스터 DB 동적 임포트**: `lib/exercises/master-db.ts`를 검색 시점에 동적 로딩하여 초기 번들 사이즈 최적화.
3. **Server Action 경계 분리 (`lib/homework-schemas.ts`)**:
   - `"use server"` 액션 파일이 `"use client"` 컴포넌트의 Zod 객체를 직접 참조할 때 발생하는 직렬화 소실 에러 원천 차단.
4. **인메모리 캐시 안전 폴백 (`lib/db-server.ts`)**:
   - `ACTIVE_HOMEWORKS_CACHE`를 장착하여 숙제 생성 즉시 캐시에 적재.
   - DB 지연 또는 Supabase 일시 장애 상황에서도 회원 뷰가 0초 만에 100% 열리도록 보장.
5. **iOS 사파리 Web Share API 차단 방어**:
   - 모바일 사파리의 0.4초 비동기 제스처 만료 정책을 고려하여, 숙제 생성 완료 직후 동기식 탭 모달을 띄워 안정적 공유 보장.
