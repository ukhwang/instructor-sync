# 📜 AI 협업 지침서 (AI Collaboration Policy)

## 1. 기본 원칙
- **Verification First:** AI 제안은 항상 실행/테스트/리뷰로 검증 후 반영한다.
- **No Over-claim:** 코드에 없는 내용은 문서에 단정적으로 쓰지 않는다.
- **Security by Default:** 키/토큰/개인정보는 프롬프트·로그·커밋에 남기지 않는다.

## 2. 개발 원칙
- Frontend(Next.js): UI/상태/요약 표시 중심
- Backend(FastAPI): 파일 파싱, 분석, 예외 처리 중심
- 스키마 기반 계약 유지:
  - 백엔드 모델(Pydantic)
  - 프론트/요약 검증(Zod)

## 3. 문서화 원칙
- README/기획서/로드맵은 코드 흐름과 일치해야 한다.
- 정량 수치는 근거가 없으면 "목표"로만 표기한다.
- 미구현 기능은 반드시 "향후 로드맵"으로 명시한다.

## 4. 보안 원칙
- `.env*`는 버전관리 제외
- 원격 URL에 토큰 포함 금지
- 유출 정황 발견 시 즉시 revoke/rotate
- 공개 전 보안 체크리스트 수행

## 5. 제출 전 체크리스트
- [ ] README 최신 반영
- [ ] 문서-코드 정합성 검토 완료
- [ ] 민감정보 노출 여부 점검
- [ ] 원격 브랜치 동기화 확인
- [ ] 공개 저장소 전환 전 최종 점검 완료
