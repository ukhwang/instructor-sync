## 공통 금지사항

실제 회원 데이터 사용, 외부 업로드, 운영 배포, 기존 Supabase 삭제, 동일 작업트리 동시 수정을 금지한다. 이 실행 계획 자체는 금지사항을 해제하지 않는다.

## 공통 완료 절차

관련 테스트 → 전체 `npm run verify` / `npm run build` → diff 검토 → 문서 상태 갱신 → `LATEST_HANDOFF.md` 갱신.
검사 실패나 미확인은 완료 증거로 기록하지 않는다. 단계 상태·완료 증거·차단 사유·다음 단계를 함께 갱신한다.

## 검증 수준

- 작성됨: 문서나 코드가 존재함. 동작 검증을 뜻하지 않음.
- 로컬 검증됨: 로컬 검사·테스트 통과. 수행 명령과 결과를 기록함.
- 일회용 환경 검증됨: 합성 데이터 전용의 격리 환경에서 DB/API 동작을 검증함.
- 실기기 검증됨: 기기·OS·브라우저·시나리오와 결과를 기록함.
- 운영 검증됨: 별도로 허가된 운영 환경에서 확인한 증거가 있음. 현재 로드맵에서 자동 수행하지 않음.

`DONE`은 해당 단계 완료 조건만 충족했다는 뜻이다. 검증 수준을 자동 승격하거나 제품 전체를 운영 가능으로 판정하지 않는다.
